# Security Log Analyzer

A local-first defensive cybersecurity application for parsing system and
application logs, detecting suspicious patterns, and presenting explainable
security alerts through an interactive dashboard.

## Planned Features

- Structured and text-based log ingestion
- Normalized security events
- Configurable, rule-based suspicious-event detection
- Explainable alerts with supporting evidence
- Interactive filtering and security event summaries
- CSV and JSON exports
- Automated tests using synthetic log data

## Technology Stack

- Python 3.13
- Streamlit
- Pandas
- Plotly
- Pytest

## Project Status

Initial development: environment and project scaffolding.

Features will be documented as they are implemented and tested.

## Security and Privacy

The application is designed for defensive log analysis. Use logs you are
authorized to access. Sample data will be synthetic, and the initial design
will process files locally.

Alerts are indicators for investigation, not proof of malicious activity.
